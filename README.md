# EFPA-PEE-RDH

Reproducible implementation of the method proposed in:

**Exact Finite-Prefix Schedule Selection for Prediction Error Expansion in Reversible Data Hiding**

## Overview

EFPA-PEE is a reversible data hiding framework based on two-stage
prediction-error expansion with exact finite-prefix and state-conditioned
schedule selection.

The method evaluates four candidate schedules:

- 2→2
- 2→4
- 4→2
- 4→4

The 2-bin mode uses the prediction-error carrier set {-1, 0}, while the
4-bin mode uses {-2, -1, 0, 1}.

Each candidate schedule is evaluated using:

- the actual ordered finite prefix,
- the actual embedded bitstream,
- the intermediate image state generated by Stage 1,
- complete reversible-stream feasibility,
- and final header-inclusive squared-error distortion.

Among the feasible schedules, the candidate with minimum final SSE is selected.

## Main Features

- Two-stage checkerboard embedding
- Directional prediction
- Deterministic local-complexity ordering
- Reversible 2-bin and 4-bin PEE mappings
- Exact finite-prefix evaluation
- State-conditioned Stage 2 processing
- Blind header recovery
- Compressed location-map support
- Exact payload recovery
- Exact original-image reconstruction
- BER = 0 verification

## Experimental Setup

The manuscript evaluates:

- six standard 512×512 grayscale images,
- 24 native-size Kodak grayscale images,
- five payload levels for each image set.

For the Kodak experiments, deterministic payloads were generated using
NumPy `default_rng` with the following seeds:

- 20260924
- 20260925
- 20260926
- 20260927
- 20260928

The same generated payload was used across all 24 Kodak images at each
corresponding payload level.

The Standard-6 experiments used fixed pre-generated binary payload files.

## Data

The benchmark images are not redistributed in this repository.

### Standard grayscale images

The Standard-6 experiments use the following grayscale test images:

- Airplane
- Baboon
- Barbara
- Fishing Boat
- Lake
- Peppers

Several of these standard test images are available from the USC-SIPI
Image Database:

https://sipi.usc.edu/database/database.php

Researchers should obtain the required images from their legitimate
public sources and use the filenames specified in the reproducibility
instructions.

### Kodak-24 images

The Kodak experiments use the 24 images of the Kodak Lossless True Color
Image Suite (`kodim01`--`kodim24`), available from:

http://r0k.us/graphics/kodak/

The experiments in this work use grayscale versions of the native-size
Kodak images without resizing.

The repository provides the expected filenames, grayscale-conversion
procedure, payload-generation seeds, and benchmark instructions.

## Scope of the Implementation

The implementation reproduces the EFPA-PEE framework evaluated in the
manuscript. The optimization is restricted to the examined four-schedule
family and does not claim global optimality over all possible reversible
data hiding mappings, predictors, or schedule families.
